03 How I build — Refy9, OKKAI

The system I run in production.

A simplified view of the platform I work on. Scroll to take it apart, layer by layer.

  1. 01 / 06

    Requests in

    • Lead developer of the core Node.js/TypeScript API (Express 5, Sequelize, Zod-generated OpenAPI, JWT + Google OAuth via a Lambda authorizer, SQS jobs); co-develop the admin API and Next.js dashboard.
    • Built Google sign-in and Gmail/Calendar consent (offline tokens, scope checks) and connected it to the wardrobe-import and calendar-based styling services.

  2. 02 / 06

    Serverless at scale

    • Run 45+ Lambda functions with GitHub Actions CI/CD that redeploys only the functions a change affects; cut cold starts to under 2 s and stabilised Aurora connections with a shared PgBouncer pool.

  3. 03 / 06

    Caching

    • Built multi-level caching into the core API: L0, L1 and L2 layers, with Redis as the shared cache in front of Aurora PostgreSQL.

  4. 04 / 06

    Infrastructure as Code & security

    • Maintain the Terraform for the whole AWS account as its main contributor and one of two reviewers; hardened IAM (per-developer keys, rotation) and made Aurora private behind an SSM bastion.
    • Prepared OKKAI for Google’s CASA security assessment (restricted Gmail scopes): rate limiting, audit logging, ClamAV scanning of uploads, SSH opened only to CI runners, and a 54-point server checklist.

  5. 05 / 06

    Async & real-time

    • Built the notification service on Firebase Cloud Messaging (500-recipient bulk sends, 140 notification types, frequency caps, EventBridge scheduling) and WhatsApp OTP via the Meta Cloud API.
    • Built the first Communities backend (SQS FIFO event feed, REST API, API Gateway WebSocket chat) and tested all 144 API endpoints against live dev, fixing 4 bugs.

  6. 06 / 06

    Observability & AI

    • Set up and run the EC2 servers for the AI team’s services (deploy CI, Docker, Nginx) and built their Grafana dashboards and alerts, with Grafana Alloy agents shipping metrics and logs to Prometheus and Loki.
    • Set up a self-hosted Gemma LLM on RunPod GPUs with the AI team (vLLM, OpenAI-compatible API), cutting third-party AI API costs.
