#What I do

I'm a backend and cloud engineer with 3+ years of work on real, live systems. I care most about the part users never see: the servers, databases, queues and pipelines that keep an app fast and up.

Here's what you can hire me for:

  • AWS infrastructure with Terraform. I write the whole AWS setup as code: network, databases, APIs, edge and security. Every change is reviewed and repeatable.
  • Serverless and event-driven backends. APIs on AWS Lambda and API Gateway, with SQS and EventBridge for work that runs in the background.
  • Caching with Redis. So the database doesn't get hit for every request and pages stay fast.
  • CI/CD. GitHub Actions pipelines that test and deploy on every merge.
  • Monitoring. Grafana, Prometheus and Loki, so you know about problems before your users do.
  • Self-hosted AI models. Serving open models with vLLM on GPU machines, behind an API your app already knows how to call.

I write the services themselves in Node.js and TypeScript.
